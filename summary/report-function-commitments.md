# 开题报告功能承诺清单

来源：`C:\Users\chyinan\Downloads\陈胤安 广州工商学院本科毕业论文（设计）开题报告 .docx`

以下内容从报告的“研究目标”“研究内容”“研究方案及可行性分析”“已具备的实验条件”中提取，作为与项目代码对照的审查基线。

## 一、平台总体能力

- 基于 Spring Cloud 微服务架构的 AI 工作流自动化平台。
- 通过可视化 DAG 编排实现 AI 能力灵活组合和自动化执行。
- 用户可创建工作流，组合文件处理、语音识别、文本生成、知识处理等可复用节点。

## 二、微服务架构与治理

- 按职责拆分用户认证、工作流管理、任务调度、AI 服务、文件管理、消息通知等服务/模块。
- 使用 Nacos 服务注册与配置管理、Spring Cloud Gateway 统一入口、OpenFeign 服务间通信。
- 使用 Sentinel、Seata 增强服务治理和可靠性。

## 三、工作流编排与执行

- 可视化创建节点、连接节点、配置流程，并支持拖拽式编排。
- 基于 DAG 解析节点依赖、调度执行、维护运行状态。
- 任务提交、异步执行、结果反馈，以及任务状态管理和异常/可靠性处理。

## 四、AI 能力节点

- 大语言模型：OpenAI、Ollama；文本生成、内容总结。
- 语音识别：Whisper；音视频转文字。
- OCR：图片及文档文字提取。
- Embedding：文本向量化，为知识库构建提供能力。
- 图像生成：Stable Diffusion、ComfyUI 接入。
- 通过统一节点接口封装并支持扩展、组合调用。

## 五、异步与实时通信

- RabbitMQ 解耦工作流提交、执行和结果反馈。
- Redis 进行任务状态缓存并支持高频状态查询。
- WebSocket 和 SSE 实时推送工作流进度、节点状态和 AI 运行日志。

## 六、前端和业务功能

- Vue 3、Vue Flow、Axios、Pinia。
- 可视化 DAG 编辑器、节点拖拽、节点配置、流程保存/管理。
- 用户管理、工作流管理、任务监控、AI 服务配置。

## 七、部署与测试

- Docker Compose 统一管理微服务及 Nacos、MySQL、Redis、RabbitMQ、Seata、MinIO 等基础设施。
- Nginx 前端资源部署和反向代理。
- 功能测试、接口测试、压力/性能测试。
- 典型场景：音视频处理、文本生成、文档解析、知识库加工；高并发任务提交、消息队列处理、服务保护、异常恢复。
