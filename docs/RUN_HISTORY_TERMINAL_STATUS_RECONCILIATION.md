# 实时终态与运行历史状态筛选

选中「RUNNING」等状态筛选下本页的一条运行后，实时事件或恢复读取可能确认其成功、失败或取消。原先详情与本页行会一起更新状态，但这条记录仍出现在原状态筛选中，分页不会补齐，也继续显示旧总数。

- 仅在当前筛选页已有的行确认终态且不再匹配状态时，从筛选结果和本页统计排除该行，并只自动重取一次当前服务器查询。复用同一工作流、状态、页码和每页条数；本页关键词依然仅在本地生效。
- 保留已选详情、日志与运行订阅，不重新打开详情，也不改变 URL 或替用户翻页。没有状态筛选、详情原本不在页内或仅从节点推断成功时，不增加列表请求。
- 实时事件可能早于列表投影落库。若重取仍含该条旧行，保留其他匹配项，说明总数尚未确认，提供「重试此页」，不循环请求。若只有列表读取失败，页首显示「运行记录加载失败」，和列表区一样提供「重试此页」，不会重读已加载的运行详情和日志。详情也有错误时，页首仍优先显示详情错误和原有重试入口。

这里不改变服务端查询、总数口径或非终态的推进规则。使用 Vue、Pinia 和内存路由的 jsdom 回归，受控响应覆盖查询保持、投影延迟、错误重试及未触发重取的对照。该验证不是实际浏览器、生产数据库或实时服务验收。
