# 从终态通知查看本次运行

同一个工作流连续运行多次时，用户不应再按通知时间到历史分页中寻找对应结果。消息中心为明确关联实例的工作流完成、失败和取消通知提供“查看本次运行”，直接打开 `/runs/run-{实例 ID}`。列表当前分页不包含该实例时，复用运行详情页的独立读取及原地重试。

## 关联范围

- 服务端 `WorkflowTerminalNotificationOutboxService` 发布 `WORKFLOW` 通道的三个终态事件，并同时写入 `payload.workflowInstanceId` 和对应的 `payload.status`。历史读取和实时消息采用同样的关联方式。
- 只接受正的安全整数实例 ID，或同等范围的十进制字符串。当前运行 API 使用 JavaScript 数字作为实例参数，因此不把超出安全整数范围的值舍入后跳转。
- 不从 `workflowId`、通知记录 ID、标题、时间或“最新运行”猜测目标。Notify 节点也可采用同名事件；它携带的 `nodeId`/`taskId` 不作为工作流终态通知处理。缺少明确关联的旧通知、AI 任务及连接消息继续显示普通消息。
- 缓存保留已确认的运行关联；升级前缓存没有此字段时，等待服务端历史重新读取补齐，不尝试用正文中的数字迁移。导航不改变全部已读、清空或未读计数契约。

## 交互和恢复

入口使用普通站内链接，保留键盘操作、复制链接及新标签页语义。路由实际变化后关闭通知面板；导航被已有确认流程拦下时，面板及入口保留，可继续操作。不自动运行、重试或修改工作流。目标详情加载失败时沿用运行页错误提示与“重新加载”，不自动跳到另一条记录。

## 本次验证

受控 Axios + Vue/jsdom 测试覆盖历史/实时通知、同名多次运行、当前历史页未包含目标、详情失败重试、取消终态、关闭重开、缓存恢复、三语入口文案和被拦截导航。运行深链测试补充不匹配搜索词下仍打开指定目标，以及刷新后的重新读取、重试迟到回执不抢回目标。没有真实浏览器布局、真实服务部署或模型执行验收。
