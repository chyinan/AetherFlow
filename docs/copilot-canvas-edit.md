# Copilot 直接编辑画布

在工作流编辑器打开 AI Copilot，选择“直接编辑画布”，输入具体要求。编辑模式默认开启；“对话”模式继续用于问答和排错。

面板右上角“新对话”会取消尚未完成的聊天或编辑请求，清空当前聊天上下文并退出旧的规划状态。画布、模型选择和旧历史记录保持不变。新对话仍能读取当前画布，但不再读取上一段聊天；刷新或重新打开面板会保留当前会话选择。

示例：

- “创建开始 → LLM → 输出流程，使用当前模型，用中文回答问题。”
- “把 LLM 节点改名为中文助手，温度设为 0.3，提示词改为总结输入文本。”
- “在摘要和输出之间插入导出文档节点，并调整连线。”
- “删除指定节点，并把上游直接连接到下游。”

AI 返回修改后，客户端先在候选图执行整批操作，再通过服务端节点目录、配置和 DAG 校验。通过后自动应用为未保存草稿，顶部“撤销”可以一次恢复整批修改，“重做”可以再次应用。保存和运行继续使用原有按钮。

生成期间手动修改画布、切换工作流或取消编辑会阻止旧响应应用。历史消息仅保留用户文本和说明，不会在刷新或打开面板时重新执行操作。模型只能使用当前可用节点目录；不支持的能力会要求澄清。节点类型、必填配置和运行时能力仍由服务端校验。

## 接口

`POST /api/copilot/canvas-edit` 接收现有 Copilot 请求结构：`prompt`、`conversationId`、`workflowId`、`projectId`、`provider`、`model` 和脱敏后的 `context`。

响应包含普通 `message` 和 `edit`。`edit.status` 为 `READY`、`NEEDS_CLARIFICATION` 或 `NO_CHANGE`；只有 `READY` 可以包含操作。操作限于 `add_node`、`update_node`、`delete_node`、`connect`、`disconnect`，每批最多 80 项，画布最多 100 个节点。

候选图经 `POST /api/workflows/drafts/validate`（`recipe: CANVAS_EDIT`）进行只读校验，保留租户归属和后端版本检查。运行时未就绪会显示草稿警告，运行按钮仍执行服务端 fail-closed 预检。

更新前端代码时，需要重建 `nginx` 镜像；Nginx 静态文件来自镜像内构建产物，并不读取 `frontend` 导出容器的数据卷。
