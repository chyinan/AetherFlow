# 节点操作按钮与画布方向键

节点容器获得焦点时，方向键继续移动选中的节点，并保留布局撤销、重做和保存行为。

节点内的「添加后续节点」「复制节点」「删除节点」按钮获得焦点时，方向键不应冒泡成为画布布局编辑，也不应产生未保存状态或撤销记录。三个按钮统一使用 Vue Flow 已有的 `nokey` 交互边界；不拦截按钮自身的 Enter、Space 或点击激活。

`WorkflowCanvas.keyboardMove.test.ts` 挂载真实 Vue Flow 与 Pinia，验证按钮焦点下四个方向键不改布局，以及返回节点容器后移动与撤销重做正常。这些 jsdom 检查不是浏览器原生键盘、视觉布局或真实后端验收。
