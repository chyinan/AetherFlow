# 工作流编辑与运行体验

本轮只调整编辑器和运行历史的使用体验，不更改工作流执行、全局变量命名、服务端权限或能力门禁。

## 1. 从上游输出选输入

转录节点的文件 URL / 文件 ID、总结节点的文本、LLM 的问题 / 上下文、导出节点的内容变量采用统一选择器。

- 正常候选只来自通过连线可到达的上游节点，显示节点名称、ID 和输出类型
- 保存的仍是原有全局变量名，不增加节点命名空间，也不会更改旧工作流格式
- 同名变量合并为一项，并列出所有写入节点。最终值仍取决于运行时写入顺序；连线不保证条件分支一定执行
- 输出键基于现有保存 mapper 的规范化配置，兼容旧输出别名、默认变量名和开始节点文件 ID 清空语义
- 删除连线、改输出名或旧绑定无法定位时，原值保留并显示提醒。运行时提供的输入可以在“高级：编辑内部变量名”中继续使用
- 固定值仍按现有执行语义优先。选择变量不会悄悄删除固定值
- 对未取得目录、无法证明的动态输出或类型显示保守提示，不把旧画布占位端口当真实输出

## 2. 使用运行结果

运行时间线支持完整文本和 JSON 展开、原文 / 格式化视图、复制完整内容。JSON 格式化仅修改空白，保留大整数、指数、重复字段和原转义。复制失败给出可见提示；运行、节点、输出或模式变化会作废旧复制状态，避免迟到回执显示到另一条运行。

历史日志与编辑器运行控制台复用同一张图像错误卡，保留等级和搜索过滤。卡片展示原因、建议、节点、相关配置字段和封闭的原始诊断标识。不会恢复被后端丢弃的秘密响应。超时和中断建议先核对远端队列，不把未知结果描述成“没有执行”，也不自动重跑。

历史页的检查入口打开相关工作流并显示节点 / 字段提示；它不声称已有跨页面字段深链。编辑器内仍使用经过当前运行归属检查的真实字段聚焦。

## 3. 运行前检查

工具栏可打开一张汇总清单：

- 阻塞：能由当前配置证实的必填、类型、枚举、变量名或保存转换错误，以及失效连线等
- 提醒：无法静态证明的输入绑定、同名变量写入冲突、能力快照中的不可用提示
- 待运行时确认：未取得目录 / 能力、图像连接真实可用性，以及服务端权限、文件和运行时校验

点击节点问题会打开该节点并定位可用字段。复合编辑器或旧配置没有对应控件时，焦点移到节点检查器，不伪称定位成功。

检查复用保存 mapper、服务端字段目录及现有结构化映射 / 循环变量验证。它不是服务端完整校验器，也不会把“没有静态阻塞”写成“保证运行成功”。现有保存和服务端 fail-closed 预检继续执行；只有确定的静态阻塞提前拦截启动。

## 4. 模板首跑向导

音频转录总结链和图像生成链可以打开四步向导：准备输入、检查配置、运行、查看成品。选择对应模板后自动展示，也可以收起后再从工具栏打开。

向导复用开始节点文件选择、Whisper 环境助手、图像连接助手与现有运行入口，不新增模型调用。模板始终标记为示例配置；只有后端确认 SUCCESS 才显示成功，不能使用另一工作流或局部推断的成功状态。运行中的按钮遵守既有防重复启动门禁。

### Whisper 向导的遮罩层级

Whisper 环境配置向导通过 Teleport 挂到 `body`，遮罩覆盖整个视口，使用与未保存导航弹窗一致的 `150` 层级，高于全局顶栏的 `100` 和通知面板的 `110`。打开向导时，顶栏也应变暗、模糊并被遮罩阻挡，不能浮在向导上方。

弹窗继续在 `90vh` 内独立滚动；关闭按钮、取消、点击遮罩和 Escape 均保留原有关闭及入口焦点恢复行为。回归测试编译实际 Tailwind 样式，比较遮罩与真实顶栏类的计算层级，并检查滚动样式、关闭和键盘焦点约束。jsdom 不提供真实绘制与命中测试，视觉覆盖仍需浏览器验证。

## 5. 历史筛选边界

历史页使用专用单页查询，工作流和状态交给后端过滤，页码和筛选条件保存在 URL。名称 / ID 搜索必须明确标记为当前页范围；完整运行 ID 可直接打开对应详情。后端尚未提供全库名称或日期查询，本轮不冒称支持。

分页列表与当前运行详情分别管理，筛选后当前详情不在列表中时明确提示；深链详情不应依赖该运行出现在当前页。旧请求不能覆盖新筛选或新选中的运行。

非历史页面的现有统计语义保留，本轮没有重构统计接口或解决其全量读取限制。编辑器恢复运行应按工作流查询，而非假定全局第一页包含目标工作流。

## 验证范围

新增测试覆盖真实 Vue 组件、Pinia、Vue Router、保存 mapper 与重开图转换。网络入口采用受控替身，执行器源码用于核对变量和校验契约。测试不构成真实后端、真实 Whisper / 图像 Provider、数据库、浏览器视觉或设备端 E2E 验证。

代码没有新增依赖。仓库没有独立 lint 脚本；应运行前端全量 Vitest、vue-tsc、Vite 生产构建及相关工作流契约脚本。具体结果见本次交付报告。
