# 历史列表本页关键词与页码

## 场景

运行历史第 2 页可见的运行，只在"本页关键词"里输入关键词并提交，筛选动作无条件把页码
写回 1：先重新取回第一页，再按关键词过滤已加载的这一页，第 2 页上命中的运行随之消失，
界面可能显示"本页没有匹配"。

## 契约

- 关键词只搜索已加载的这一页，不改成全库模糊搜索
- 只改关键词（含清空关键词）时保留当前页码，不重新取数
- 工作流 ID、状态属于服务器筛选：这些筛选变化时回到第一页
- 筛选条件、页码仍写入 URL，前进后退与刷新保持条件
- 分页总数、详情深链与独立运行详情不受影响

## 验证范围

前端组件测试覆盖：第 2 页提交关键词后页码保持、不额外请求列表、命中项仍在页面上；
清空关键词同样保留页码；既有服务器筛选回第一页的行为保持不变。
