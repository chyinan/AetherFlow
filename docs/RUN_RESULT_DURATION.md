# 运行结果时间线耗时

节点耗时为已测量数值时，时间线按毫秒显示，包括合法的 `0ms`。完成时间与开始时间落在同一毫秒，或者运行详情明确返回 `durationMs: 0`，都不能再显示为“等待中”。

本次修改只区分零值与缺失值，不改变运行或节点状态推导。没有耗时信息时保留原等待提示；复用节点仍优先显示复用提示；正耗时展示、结果展开、原文/格式化和复制行为保持原有契约。

回归覆盖运行详情 API 映射的显式零值、同毫秒时间戳回退、运行事件恢复出的零值、未知耗时更新为零、正值和复用节点。测试使用真实映射与 Vue 组件、受控 API 响应和 jsdom，不代表生产后端计时精度或真实浏览器验收。
