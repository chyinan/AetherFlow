# 运行结果时间线耗时

节点耗时为已测量数值时，时间线按毫秒显示，包括合法的 `0ms`。完成时间与开始时间落在同一毫秒，或者运行详情明确返回 `durationMs: 0`，都不能显示为“等待中”。

如果节点已经成功、失败或跳过，但还没有可用耗时，时间线显示“耗时暂无数据”。正常实时完成事件可能先确认节点状态，后续刷新才取得耗时；历史记录若缺少起止信息，也不会将节点显示为等待或虚构数值。真正排队或暂停的节点继续使用原提示，复用提示仍优先。有了实际耗时后，时间线显示新数值。

该显示不改变运行或节点状态、耗时计算、结果展开、原文/格式化、复制或重跑行为。回归覆盖三语历史详情、实时成功与失败事件、跳过与暂停、缺失耗时补齐，以及明确零值、同毫秒事件、正值和复用节点。使用真实前端映射和组件、受控 HTTP/SSE 与 jsdom，不代表生产后端计时精度或真实浏览器验收。
