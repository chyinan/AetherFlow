# 工作流入口与模板首跑的请求归属

## 修复的用户路径

1. 打开未指定名称或项目的空白工作流入口，辅助列表尚未返回时进入另一工作流或命名草稿，并编辑或应用模板。原实现等辅助读取完成后再次清空全局画布，导致新内容、身份和撤销历史丢失；离页重入也会受影响。现在只在进入空白入口时同步清理，不在旧读取结束后重置新画布。
2. 打开模板列表后切到另一工作流，或离页重入。原请求的成功会在新页打开弹框，失败会覆盖新页运行错误，旧等待也会暂时阻塞新页重新加载模板。现在成功导航关闭旧弹框并废弃请求代次，卸载释放旧等待；旧成功、失败和 finally 均不能覆盖新请求状态。拒绝导航仍保留原页请求和选择。
3. 模板列表尚未返回时成功导入 ComfyUI，地址甚至草稿 ID 都可能不变，但画布已经替换。旧模板请求不再弹窗、抢焦点、覆盖新画布的错误或挡住重新打开；已打开的旧选择器也关闭。取消或失败的导入不影响原画布的模板选择。
4. 未保存模板 A 点击运行，等待运行历史或输入准备时替换为模板 B。两张画布的 ID 都是 new，仅核对 ID 会让旧点击保存并运行 B。现在派发前绑定点击时的编辑代次；准备期间换模板或编辑配置后，必须重新点击运行。未改内容、拒绝模板替换和正常首次保存后的地址规范化仍可继续。
5. 在同一画布浏览模板不会清除或覆盖启动失败；即使还有保存失败，模板读取错误也在编辑器中单独显示，并通过原模板按钮重试。重试时隐藏上一条模板错误，只发送一次读取；成功打开选择器后恢复按钮名称，关闭后可回到原入口。只有显式应用模板才替换画布；成功读取到空列表仍显示「暂无可用模板」。
6. 模板读取完成或选择器已经打开时，如果出现未保存离开确认，只有离开确认接管焦点、Escape 和页面滚动。选择留页（或后续路由守卫拒绝）才恢复同一列表，不重复读取；实际离开后不会打开原选择器。等待期间的模板读取失败仍可在留页后重试。
7. 首跑向导或预检占据一部分编辑区时，短窗口、窄屏换行或缩放会进一步压缩画布。模板弹框改为相对整个编辑器限高，超出时由弹框自身滚动和换行，不再依赖画布滚动。关闭、模板选择和未保存离开仍使用原有焦点与确认流程。

8. 模板首存成功把草稿地址换成正式地址时，当前画布不需要重载。同一画布已打开的模板选择器、仍在读取的模板列表和可重试的失败提示继续保留；导航守卫期间读到的列表在地址确认后按原打开意图继续。实际切换画布或离页时仍废弃原选择器。

## 行为边界

- 派发后继续编辑同一工作流时仍记录原运行回执，由已有未保存导航确认决定是否离开；不会把服务端已确认的运行隐藏成回执丢失。
- 请求失效只停止旧回执对当前页面的影响，不承诺中止已发出的网络请求或撤回服务端已经收到的运行。
- 模板和节点能力仍通过原有接口读取，服务端仍执行最终定义和能力校验。
- 未修改后端、Provider、依赖、设置或权限，也不改变已有运行重试的幂等确认语义。
- 仅以受控 API 验证页面流程，不能据此声称真实音频转录、模型生成或文件成品已经成功。

交互验证使用 jsdom、真实 Vue/Pinia/Router 和页面组件；API 传输及部分无关组件受控替换。真实浏览器布局、浏览器进程历史、实际网络时序、后端、数据库和 Provider 不在此次验证结论中。

## 模板读取期间继续编辑

点击模板后如果还在读取，用户在同一画布的编辑区继续输入、开始输入法组合或更改配置，模板列表仍可读取，但迟到的成功回执不自动弹出选择器或移动焦点。可再次点击模板主动打开。失败仍以非模态提示显示，可原地重试。仅在编辑区继续输入时让更晚的用户操作优先；未保存离开确认的留页恢复，以及导入取消和失败的原有行为不变。回归挂载真实属性面板并使用受控目录响应，不执行模型或保存流程，也不等同于实际浏览器输入法验收。
