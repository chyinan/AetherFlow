# 文本模板检查器语法提示修复

- 复现场景：选择文本模式的模板转换节点，或由结构化映射切回文本模板。
- 原因：中、英、日三种语言的提示和语法标签都直接含有 `{{ variable }}`。Vue I18n 把它作为消息语法编译，抛出 `Not allowed nest placeholder`，阻断检查器渲染。
- 修复：仅将提示里的模板语法改为命名插值数据，显示内容和训练/执行模板、保存结构均不变。不清空用户模板，不改全局编译器行为。
- 验证：新增三语言真实 NodeInspector 挂载回归，覆盖文本模式、结构化模式往返、模板内容与输出变量保留；修复前这三例均以嵌套占位符错误失败。三语言回归、结构化编辑器持久化/反馈/映射和额外受控 HTTP 模式切换、422 保存重试及重开组合，共 6 套 63 项通过；vue-tsc 类型检查与 Vite 生产构建通过。
- 限制：组件回归采用 jsdom；真实后端、模型执行及完整演示工作流未由这些测试验证。
