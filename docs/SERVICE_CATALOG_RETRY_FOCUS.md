# 服务能力目录的重试焦点

普通用户在「服务能力」页读取失败后，可以通过错误区的「重试」再次查询。加载状态会替换错误区。重试按钮若正持有焦点，在它被移除前将焦点放到持续可见的页标题。标题可被程序聚焦，但不添加普通 Tab 停靠点。若按钮未聚焦，或用户随后移到其他控件／离开本页，读取回执不会重新抢占焦点。

保持原有读取、在途去重及成功／失败／空目录呈现。顶部「刷新能力」、求助入口、服务是否可用的判断以及 API 查询路径不变；不会新增请求或修改配置。

回归用真实 Vue、Pinia、内存路由与 Axios 响应拦截器，底层 adapter 受控且不联网。覆盖持续等待、再次失败后重试、恢复目录、重复点击、主动移动焦点及离开／返回期间的回执。合成 DOM 焦点不等同于真实浏览器的键盘、滚动或辅助技术验证。
