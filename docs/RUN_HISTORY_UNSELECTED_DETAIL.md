# 运行历史：列表未选中时不显示旧详情

从已有运行的详情回到工作台，再点击「完成结果」的「查看更多运行」，打开的是不带运行 ID 的筛选列表。列表尚未返回、读取失败或没有匹配结果时，不将上次详情或编辑器共享的运行缓存当成当前选中项，也不展示该次运行的日志错误、节点操作或审批弹窗。取消清理的详情读取仅随当前路由选中的运行进行，不因打开列表而重新读取上一条运行。

列表读取失败时，页面错误提示的「重试」会按当前筛选重取列表，即使共享缓存还保留上次详情的日志错误。只有明确打开运行 ID 时，才可能单独重试读取该运行。列表成功返回非空结果后，仍按原有规则打开首条记录；带运行 ID 的深链或手动打开的记录仍可独立于列表筛选查看。列表等待和未选择提示沿用现有中、英、日文案。当前页面不清除共享缓存，不额外改变运行选择、取消、审批、重跑的请求协议或服务端行为。

回归使用 Vue、Pinia、内存路由和 jsdom，挂载实际工作台入口、运行页、日志、时间线和审批弹窗。受控 API 覆盖列表延迟、失败后重试、空结果后按 ID 打开、深链与列表失败并存，以及旧日志错误、审批显示与取消清理读取的归属。未提交审批，也未访问真实后端或进行实际浏览器、辅助技术验收。
