# ComfyUI 执行图的"未编辑"与"明确清空"

## 场景

节点的 `workflow` 存着导入的原图 A，`workflowJson` 存着 API 执行图。把执行图改成 B 后
再清空，界面显示为空/无效；映射层却把空串转成缺省，保存后配置里没有 `workflowJson`。
执行图解析按"`workflowJson` 缺省就用 `workflow`"的规则，于是悄悄执行原图 A：界面显示
与实际执行不一致，运行结果也无法解释。

## 契约

- 映射层区分"未编辑"（字段缺省）与"明确清空"（空串）：明确清空保留为空串，不再被抹成
  缺省
- 未编辑仍按既有契约回落原图（`workflow`），旧数据不受影响
- 明确清空时执行图解析显式报错，不会偷偷执行原图
- 前端预检把明确清空判为阻塞项，提示恢复 API 格式 JSON 或移除该配置
- 服务端节点目录校验不额外收紧：空执行图字段仍属既有兼容取值
- 非 ComfyUI Provider 不受该规则影响

## 验证范围

- 前端映射：空串保留为 `''`，缺省与 null 仍然省略
- 前端预检：ComfyUI 节点明确清空执行图产生阻塞项
- 后端执行图解析：缺省回落原图；明确清空显式报错
