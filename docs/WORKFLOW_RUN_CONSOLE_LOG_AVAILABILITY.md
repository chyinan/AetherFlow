# 编辑器运行控制台的日志状态

编辑器右侧的运行控制台会显示已加载的日志，并继续展示收到的实时日志。读取已保存日志遇到可重试故障时，控制台提示当前内容可能不完整；不会把尚未读到的日志当成「暂无运行日志」，也不会隐藏已有记录。

提示只对应控制台正在显示的运行。点「前往运行详情重试」打开该运行，沿用运行详情原有的日志读取和重试入口。链接不会在后台自动跳转、重跑工作流或改变实时订阅；离开编辑器仍经过原有的导航守卫。读取成功后恢复真实空状态或正常日志列表。

控制台只显示当前画布的运行和日志（同一后端工作流定义的别名仍匹配）。切换工作流时，旧运行的状态、记录和详情链接不会被当成新画布的结果。查找当前工作流的运行失败时，可在控制台原地重试，只重新读取运行和必要日志，不重载画布、不写入，也不启动运行。只有读取成功并确认没有运行时，才回到空状态。已选中运行的归档日志重试仍通过原「前往运行详情重试」入口。

受控回归使用实际 Vue、Pinia、Vue Router 和 Axios 拦截器。未执行真实浏览器、后端或实时连接验收。
