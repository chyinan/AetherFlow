# 项目弹框键盘闭环

## 交互契约

- 新建项目、新建工作流和重命名工作流使用已有 `useModalFocus`，打开后焦点进入当前表单
- 项目页背景 header/main 在弹框打开期间使用 `inert`；尝试把焦点移到表单外时，既有焦点管理会将其带回
- 首项 Shift+Tab 和末项 Tab 在当前可用控件之间循环；创建等待时禁用字段不参与循环，关闭入口仍可用
- Escape、顶部关闭和底部关闭复用同一关闭函数，关闭后恢复仍存在且可聚焦的原触发器
- 关闭或离页时释放键盘监听和 body 滚动锁；再次进入页面可重新打开
- 两个表单提供对应标题/说明的具名模态语义，并限制表单最大高度、保留内部纵向滚动入口

保留已有的创建代次保护、提交参数、失败提示和工作流导航。这里不自动取消已经提交到服务端的请求。

## 与重命名恢复改动组合

工作流的 Escape 和按钮关闭统一调用 `closeWorkflowPanel()`。与重命名恢复改动组合时，必须保留该函数已有的 `workflowPanelGeneration` 失效处理及等待/失败状态清理；不能改成直接赋值关闭标志。组合回归覆盖“重命名等待 → Escape → 新建工作流 → 旧成功”，旧回执不得关闭新草稿或改变其当前焦点。

## 验证范围

`ProjectsPage.keyboard.test.ts` 通过真实页面、项目 store 和 API 层测试，Axios 最底层使用受控内存传输；正常 USER 为合成会话。覆盖三种入口的焦点、双向边界、Escape、两个关闭入口、重复打开、具名语义，以及创建等待/失败、旧创建回执和离页清理。

DOM/jsdom 验证不等同于真实浏览器的原生 Tab 默认导航、短屏几何、视觉、原生滚动、屏幕阅读器或真实后端授权验收。
