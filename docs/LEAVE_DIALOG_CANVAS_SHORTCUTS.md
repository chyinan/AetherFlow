# 离开确认弹窗期间的画布快捷键

## 场景

未保存离开弹窗打开、焦点在"取消/保存并离开"按钮上时，Ctrl/Cmd+Z、Ctrl/Cmd+Y、
Ctrl/Cmd+Shift+Z 仍然改动画布。画布区域虽然被 `inert` 标记，但窗口级快捷键监听仍然
生效：用户随后选择保存并离开，保存的是非预期版本。

## 契约

- 离开确认弹窗打开时隔离画布撤销/重做快捷键：不得改动画布，也不得改变撤销重做历史
- 弹窗关闭后撤销重做快捷键立即恢复可用
- 输入框中的原生撤销、Tab 焦点移动与 Escape 行为不受影响（弹窗自身处理）
- 弹窗内的按钮点击、保存、放弃未保存改动等既有行为不变

## 验证范围

前端组件测试（jsdom）覆盖：弹窗打开时 Ctrl/Cmd+Z 不撤销、Ctrl/Cmd+Shift+Z 与
Ctrl/Cmd+Y 不重做、弹窗关闭后快捷键恢复。未做真实浏览器键盘与视觉验收。
