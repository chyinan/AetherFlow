# 文本摘要模板的提示词绑定

## 场景

"文本摘要"模板的 LLM 节点把固定提示词写成字面量 `{{ prompt }}`。固定值优先于变量绑定，
运行时不插值，模型收到的是 `{{ prompt }}` 本身；用户修改输入也不能替代它。

## 契约

- 模板改用既有变量绑定：`promptVariable=prompt`，不再写固定提示词
- 固定提示词与变量绑定的既有优先级不变：用户明确配置固定提示词时仍优先
- 不为一个模板扩展全局插值规则
- 界面、保存与实际请求一致：前端映射只在非空时保存固定提示词，变量绑定原样保留
- 媒体摘要模板的节点结构不变

## 验证范围

Java 回归覆盖：模板不再含固定 `prompt`、含 `promptVariable=prompt`；LLM 节点在只有变量
绑定时取到工作流输入变量；显式固定提示词仍优先；媒体摘要模板节点结构不变。
