# 图像连接向导的字段校验

添加或编辑 ComfyUI / Stable Diffusion WebUI 连接时，测试允许先不填名称。地址测试通过后，如果保存时缺少名称，提示紧跟名称字段并将焦点移回该字段；填入有效名称后提示消失，已有的地址检测仍有效，不需要重测。在测试时输入了无效地址，则会定位地址字段。未改正的字段不会因为编辑其他字段而丢失提示。

字段校验错误与测试或保存请求失败分开处理：请求失败不会把输入框标记为无效或转移焦点。更改地址或 Provider 仍会让旧测试失效，只有用户再次点击测试或保存才会发送相应请求。关闭向导清除草稿与本地校验，既有保存继续规则不变。

前端回归挂载真实 Vue、Pinia 及传送到 document body 的对话框，覆盖三种语言的名称恢复、地址校验、显式重试及关闭；使用受控连接接口，不代表真实浏览器、辅助技术、后端或图像服务验收。

在同一循环体打开多个图像生成或放大步骤时，面板共用正在读取的服务连接目录；目录可用后，各步骤按自身选择分别检测并显示模型选项。首次读取失败后，在任一面板刷新可补齐仍在等待的步骤。刷新不会重新启动其他步骤已取消或已完成的检测。
