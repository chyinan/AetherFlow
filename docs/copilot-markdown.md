# Copilot 回复中的命令与链接

Copilot 回复支持标题、列表、粗体、斜体、行内代码、HTTP(S) 链接和多行代码块。

行内代码作为原文展示，例如 `ffmpeg -i input_file_h264.mp4` 中的下划线和星号不会再次按 Markdown 排版。链接目标中的文件名与查询参数同样保留原值，链接标签仍可使用粗体和行内代码。普通文件名或模型名内的下划线不作为斜体标记；独立的 `_强调_` 和 `__粗体__` 仍可使用。

这些规则只影响回复展示，不会执行命令、自动下载素材或更改发送给模型的消息。多行代码块继续保留换行和缩进。

流式回复中断或提供方失败时，已收到的内容保持原样，失败提示作为该回复的独立状态显示，不追加到模型正文或代码块内。即使中断时代码围栏尚未闭合，复制代码也不会带上客户端失败提示。首段内容到达前的失败同样展示状态；不会自动重发，用户仍可显式续问或开启新对话。
