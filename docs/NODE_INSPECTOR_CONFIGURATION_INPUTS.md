# 节点检查器配置输入

## 数字输入留空与显式零

循环及迭代节点的最大次数输入留空时，继续沿用保存映射的默认值：循环为 10，迭代为 12。迭代并发数留空时默认为 1。界面保留空白，展示默认值占位及说明，而不是把空白显示成显式的 0。

显式输入 0 的最大次数仍保存为 0；其他已输入数字及后端/映射的规范化规则不变。此调整只覆盖上述输入框，不改变循环执行、并发或保存接口。

知识检索的 Top K 留空时使用原有默认值 3；数字框保持空白并提示默认值，滑杆显示将保存的 3。重新输入数字或移动滑杆仍按原有 1–50 范围保存。

## 知识检索的高级设置

元数据过滤条件的 JSON 示例是语言无关的字面值，不交给国际化消息编译器解析。中、英、日界面都可展开高级设置并编辑过滤 JSON、Top K。示例展示不改写用户输入，原有 JSON 校验和保存行为保持不变。
