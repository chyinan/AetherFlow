# 节点检查器的运行归属

节点检查器展示的最近输出、耗时及循环逐项结果，只能来自当前画布对应的工作流运行。节点 ID 可能在不同工作流中重复，不能仅凭节点 ID 关联结果。

## 行为

- 使用与工作流页面现有门禁一致的归属判断：工作流 ID 相同，或有效的后端定义 ID 相同
- 切换到另一工作流后，即使新运行历史仍在加载或读取失败，也不显示前一工作流的节点输出和耗时，不向前一实例读取批次结果
- 匹配运行恢复后，检查器自动展示该运行的节点输出、耗时和批次结果；同定义的别名地址保持可用
- 没有匹配运行时，保留当前节点自身运行信息或既有等待提示，不改写全局当前运行或停止其订阅
- 旧批次读取的迟到成功或失败不能覆盖新归属上下文

## 验证边界

回归使用真实 Vue、Pinia、Vue Router memory history、WorkflowPage、NodeInspector 与 LoopRunResults，API 和画布几何使用受控替身。覆盖跨工作流同名节点、历史失败和等待、正常恢复、同定义别名、普通节点及批次请求交错。

本次不改后端结果接口、运行生命周期或权限；不将运行事件属性宣称为后端未提供的业务输出。测试不等同于真实浏览器、后端或 Provider 验收。
