# SUMMARY 的 Provider 与模型显示

## 场景

SUMMARY 面板未配置 Provider 与模型时，界面显示 `ollama` 与 `qwen3.5:9b`，但保存时这两个
字段被省略，运行采用部署默认与自动路由：界面显示与实际执行不一致，用户以为已经选定了
某个模型。只改模型时，界面仍然显示"已选中的 ollama"，而存储里并没有这个 Provider。

## 契约

- 未配置 Provider 时显示"服务默认（自动路由）"，不显示并不存在的选定值
- 未配置模型时输入框为空并以"服务默认"作提示，不显示假定的模型名
- 已配置的取值原样显示（含大小写与历史遗留取值），界面与存储一致
- 未配置时不写入 Provider 与模型：执行沿用部署默认与自动路由，不把旧工作流静默钉死到
  某个新模型
- 只改模型不隐式写入 Provider
- 预检与执行沿用既有语义（Provider/模型是可选覆盖项）

产品取舍说明：选择"显示服务默认"而不是"持久化默认 Provider/模型"，避免把既有工作流钉死
到当前部署并不存在的模型上；产品若需要固定默认，应由部署侧默认值表达，而不是由编辑器
写入历史工作流。

## 验证范围

前端组件测试（jsdom）覆盖：未配置时显示服务默认、已配置时显示实际值、只改模型不写入
Provider、未配置时保存结果不含 Provider 与模型。
