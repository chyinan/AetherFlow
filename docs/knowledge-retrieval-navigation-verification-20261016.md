# 知识库详情检索的导航与局部状态恢复

## 使用场景与修复

同一正常用户在 ready 知识库 A 点击搜索后，若请求仍在等待，返回列表再打开 ready 知识库 B，B 会沿用旧的局部等待状态，导致非空查询也不能提交。A 已失败后离开，或返回列表后 A 才失败，也会把旧局部错误带到 B。

修复只涉及 `frontend/src/pages/knowledge/KnowledgePage.vue` 的页面局部检索生命周期：

- 返回列表、打开详情时递增请求标识并清理局部等待／错误
- 每次有效检索捕获自己的标识，只有当前标识的失败与结束回调可更新局部状态
- 不取消后端请求，不修改 API、store 的检索结果处理、身份、权限或文件功能
- 保留查询去空格、topK 规范化、当前等待时的按钮禁用，以及当前失败后的保留查询和显式重试

同一个知识库离开后重新打开，也会获得新的局部生命周期，避免只比较 dataset ID 而误认旧请求为当前请求。
