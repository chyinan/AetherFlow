# 工作流任务连续性

## 范围

本次基于维护分支 `b66e260982c0bc9f5e814f7ef4e7abadeb9e5b8e`，只完善五条已授权的前端路径：离开前保存、失败节点回到编辑器、脱敏求助、节点能力重检、成品返回来源运行。不改变服务端执行、重试、权限或部署契约。

## 离开前保存

- 会替换当前画布的站内导航提供“保存并继续”“放弃修改并离开”“留在此页”
- 保存成功且没有更新的未保存编辑时继续原来的导航，保留 push、replace、后退和前进的历史语义
- 保存失败保留画布、目标页面和错误，可在同一弹窗重试；保存期间产生新编辑时继续留页，要求再次保存
- 重复点击不会发起第二次保存。新导航目标取代旧目标，但旧保存响应不能自动批准新目标；留页、Escape、卸载后，旧响应不能把用户送走
- 取消离开不撤销已经发出的保存请求；该请求仍可能在服务端完成，当前工作流可接受其合法保存结果，但不会继续已取消的导航
- 来源节点、来源运行和 hash 的纯定位变化不替换同一个画布，不弹离开框或重新读取定义，保留未保存图和当前错误；工作流路径、项目或初始化名称改变仍受保护
- 刷新、关闭标签和离开站点继续使用浏览器原生 beforeunload 提示；不承诺在这些动作中异步保存，也不新增自动持久草稿

## 从失败节点回到画布

- 运行时间线上的失败节点新增“编辑此节点”，使用明确的工作流 ID、精确节点 ID 和来源运行 ID
- 来源运行独立读取，不接管编辑器正在显示的当前运行或实时订阅；验证运行归属和失败节点后才选中并居中
- 错误摘要只在页面显示，并提供“返回来源运行”；原历史筛选、分页、查询和锚点保持在受校验的返回地址中
- 节点删除或替换时明确显示不能定位；循环或子流程执行节点不拆分 ID 猜测对应根节点
- 来源读取期间，如果已切换节点、编辑（包括尚未解析的输入）、使用键盘或移动/缩放画布，迟到结果只补充来源详情，不再自动切换检查器或移动视图；“定位此节点”仍可主动使用
- 同一来源的自动定位只尝试一次；保存后的地址规范化可以重新核实来源，但不会抢回当前选择。真正切换来源运行或节点时才产生新的自动定位意图
- 来源定位仅保留初始布局重试；新增、复制、删除节点、后续编辑或手动交互会取消旧定位，后续节点测量不会重新把画布拉回原节点
- 当前运行接口没有提供源定义版本。编辑器明确提示正在查看当前定义及已知版本，不能确认与运行当时完全一致；相同节点 ID 只用于定位，不代表配置仍相同
- 普通保存规范化工作流地址时保留来源上下文。旧运行或旧日志的迟到响应不能覆盖新的来源

## 脱敏求助

- 服务能力目录和节点检查器提供可预览的求助摘要，用户主动复制后自行选择接收方
- 默认只有能力类型、安全错误类别和生成时间。能力类型及类别使用白名单，未知值不会原样进入摘要
- 工作流和节点定位默认关闭，用户主动勾选后才加入；非标准标识进一步隐藏为 `[redacted]`，预览始终展示实际复制内容
- 不接收或复制后端原始错误、输入正文、节点配置、内部 URL、账号信息或密钥；页面原有错误显示与求助摘要分开
- 关闭、切换对象或身份后不沿用上次定位选择；重复复制、失败重试和迟到剪贴板响应都有对应状态保护
- 不自动发送外部消息，也不新增对管理员私有数据的访问

## 节点内重新检查能力

- 在当前节点直接重新获取既有节点目录和运行能力，现有预检自动重算；不保存、重建或启动工作流，不改变选中节点
- 重复点击、取消、节点或工作流切换、身份变化及卸载会阻止旧结果更新当前能力；全局目录请求仍按最新请求顺序处理
- 请求失败或快照不完整显示未确认，不把旧快照或演示数据当成当前可用；目录失败与能力失败分别反馈
- 保留原目录刷新，以及 Whisper 环境和图像运行环境的专用入口；能力快照不替代配置校验与服务端 fail-closed 预检

## 成品返回来源运行

- 当前运行成品筛选增加“返回来源运行”。通过运行详情进入时保留原历史筛选、分页、重复查询与 hash
- 直接打开 `/files?runId=...` 仍可返回对应运行详情，不依赖本地缓存
- 返回地址只接受同一运行的站内详情路径，外站、其他运行和控制字符地址回退到该运行的基本深链接
- 清除筛选保留其他文件页查询与 hash，同时移除本次运行筛选及其返回上下文

## 验证与边界

新增与既有回归覆盖保存失败重试、迟到响应、同目标和新目标重复导航、取消、卸载、浏览器历史、纯定位查询、精确节点定位、删除节点、版本提示、安全摘要、身份变化、复制失败及成品深链。

验证直接运行工作区已有依赖对应的 Node 入口，没有安装依赖或修改锁文件。最终测试数量、类型检查、构建和静态契约结果见本次 PR 的验证记录。

这些验证使用单元测试、受控 API 响应、Vue Router memory history 和 jsdom DOM。它们不是实际浏览器的像素、滚动几何或生产后端验收。真实 Vue Flow 居中动画、浏览器历史按钮、软键盘、窄屏及 200% 缩放、辅助技术、原生刷新提示、系统剪贴板权限和真实 Provider 均仍需在已授权的浏览器环境验收；后端 Java、部署、压力及故障测试未包含在本次前端变更验证中。
