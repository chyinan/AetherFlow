# 设置弹窗、通知与侧栏标签的响应式契约

## 范围和证据

本次以维护分支 `50ee4e045544c683727be8b86cdc2ea34ddd2b06` 为基线，仅修复已讨论的设置 Provider／成员记录弹窗、顶栏通知、侧栏标签及相关长标识显示。没有变更权限、请求负载或业务保存语义，也没有合并、部署或修改原有工作区。

修复前的证据来自源码检查：

- Provider 和成员记录表单固定居中且 `overflow-hidden`，没有视口高度上限或内部滚动区
- 通知宽度最多为视口减 32px，但相对右侧按钮组又向左偏移 52px，叠加顶栏边距会越过窄视口左边缘
- 侧栏标签是滚动 `nav` 的绝对定位后代，不能通过祖先的 `overflow-visible` 逃离滚动容器裁切

这些是已核实的 CSS 风险，不是修复前后浏览器截图复现。

## 修复后的契约

- 两个设置弹窗的总高度不超过动态视口减 32px，并保留 `vh` 回退。标题和操作区不收缩；提示、字段、长错误在 `min-h-0` 内部滚动区中滚动
- Provider 标题可省略且保留完整标题与无障碍名称。内容区允许长 URL、标识、标签和错误在任意字符处换行
- 真实表单位于有名称的 `dialog` 区域内。背景内容在打开期间 inert；焦点进入弹窗并循环，Escape 复用现有关闭守卫，保存中仍不允许退出
- 关闭、成功保存或组件卸载时恢复背景滚动；原触发器仍存在且可用时恢复焦点。错误留在当前表单，关闭再打开时清理既有错误／密钥草稿
- 顶栏工作区允许收缩并截断，完整名称保留在 title 中，右侧按钮不被挤出
- 通知通过 Teleport 放到 body，以视口右侧 16px 定位；高度受动态视口约束，内部滚动。Escape 返回通知按钮，外部指针、焦点离开、路由变化和账户菜单均关闭通知
- 侧栏链接保持 40px 高度并允许 nav 滚动。标签通过 Teleport 逃离滚动裁切，支持键盘焦点、Escape、滚动和窗口尺寸变化时关闭，并限制宽度及纵向位置

## 已执行的合成验证

- 设置页和布局的组件回归覆盖 Tab／Shift+Tab、Escape、保存中的关闭守卫、关闭后焦点与 body overflow 恢复、反复打开、卸载和长错误
- 长错误更新保留 DOM 滚动区节点和 scrollTop。这个断言不模拟浏览器滚动几何或触摸手势
- axe 检查两个设置弹窗和通知区域的适用语义规则；关闭颜色对比规则，因为 jsdom 没有真实渲染
- 布局契约检查内层 `min-h-0`、滚动、固定操作区、动态视口回退、长文本换行及浮层 Teleport 目标
- 验证命令：`npm test`、`npm run build`、`npm run check:sidebar-motion`、`npm run check:notifications`、`npm run check:settings-data-access-badges`。本轮直接调用已有依赖对应的 Node 入口，未安装依赖或修改锁文件
