# 从节点的加号菜单添加后续节点

加号菜单使用与画布左侧节点目录相同的可用性状态。若目录给出当前环境不可用的原因，选项会直接显示它，不必先尝试添加。

- 目前不可用且没有节点级运行环境配置入口的选项（例如未启用模型服务时的 LLM）不可选；菜单保持打开，不会误触发添加失败提示。
- 图像生成、图像放大和 Whisper 仍可先添加，再在检查器中配置。该提示不表示节点可执行，保存与运行前的现有校验不变。
- 目录恢复后，打开的菜单同步更新；已可用的选项仍按原逻辑添加并连接到当前节点。

回归用真实加号菜单、画布节点与 Pinia store，模拟节点目录的可用性及画布视口。验证的是前端呈现与普通选择，不是浏览器视觉或真实服务连接、执行。
