# 角色化工作台：产品契约与验收

## 范围和设计顺序

本轮基于维护分支 `11f49cffb93756388ae0db28a89e8ed1d0bbee25`。先确定角色与任务路径，再实现交互、请求和后端端点边界，最后执行合成回归。PR #31 的显式输入和按运行成品入口尚未合并，本轮不复制其改动；工作台把结果入口链接到现有运行详情，合并 #31 后沿用详情中的本次成品入口。

### 1. 真实登录角色先于界面别名

- `User.role` 对应登录响应的 `rawRoles`。`USER` 使用个人工作台；`ADMIN`、`OWNER` 使用管理概览，也能进入自己的工作台
- 前端历史 `owner` / `operator` 是显示/路由兼容别名，不得单独授予管理能力。缺失或未知的真实角色默认无管理能力
- 设置中的 `SettingsMember` 是当前账号维护的成员记录。`Owner` / `Admin` / `Operator` / `Viewer` 标签不创建登录账号、不发送邀请、不赋予或撤销账号权限，也不代表真实付费席位
- 前端能力判断组织导航、界面动作和请求。后端必须独立验证令牌、角色及资源归属；隐藏入口不构成授权保障
- 管理员身份不会自动读取所有用户的私有项目、工作流、运行、知识库或文件。本轮不修改个人资源的服务端归属规则

### 2. 普通用户闭环

`登录 → 我的工作台 → 继续编辑 / 新建或导入 → 编辑器预检与运行 → 运行详情 → 失败恢复或查看结果`

- 工作台只读当前登录账号的既有工作流和分页运行接口
- 进行中包含 PENDING、RUNNING、RETRYING、WAITING；各状态最多取 4 条并按运行 ID 去重，避免无界加载历史
- 状态分页不是同一事务快照，不把页内数量虚称平台或全部进行中总量
- 最近完成与失败入口定位具体运行，复用已有取消、重连、人工审批、失败节点恢复与结果逻辑
- 已保存工作流列表不承诺恢复尚未保存的编辑器草稿；不擅自重置编辑器
- 用户服务页读取后端工作流能力快照，显示可用、不可用原因、未知状态与下一步。不呈现共享 Provider 配置、内部端点或路由治理操作
- 设置默认个人偏好，管理深链接解释原因后回到可用区域。用户仍可访问自己的数据和 API 使用说明

### 3. 管理员闭环

`登录 → 管理概览 → 成员记录 / 共享服务配置 / 平台状态 → 查看错误或重试 → 返回我的工作台`

- 管理概览不为了统计而加载私有项目、运行或文件
- 成员记录操作明确实际作用，失败保留可恢复状态，重复写操作互斥
- 共享 Provider 配置、主备切换、恢复和向量配置在请求前再次检查管理能力；普通用户挂载设置页不会调用管理员向量配置
- 平台状态逐来源显示成功、无权限、暂不可用，支持单项重试。未知值不能当零或正常，不把失败静默折叠成一排占位符
- 身份/角色变化使当前读取失效并清理管理草稿；同一身份的普通刷新不应丢弃正在编辑的设置

### 4. 最小后端端点契约

以下现有共享平台运维读接口要求 ADMIN / OWNER：

- `/workflow/runtime/metrics`
- `/workflow/node/metrics`
- `/workflow/embedding/metrics`
- `/workflow/ocr/metrics`
- `/task/metrics`
- `/file/status`、`/file/metrics`
- `/auth/status`、`/auth/metrics`
- `/gateway/status`

其余既有管理员配置/策略/遥测端点保留原契约。使用精确路径，不把个人运行观察、任务进度、工作流能力目录或健康探针按前缀一起封禁。网关本地 `/gateway/status` 不经过下游 GlobalFilter，专用 WebFilter 复用相同角色及撤销校验。公开健康检查继续使用 `/actuator/health`；部署与性能脚本同步迁移。

## 两项已确认问题

1. 设置页将 computed ref 当布尔值，导致普通用户仍读取向量配置。本轮按真实管理员能力控制挂载、动作和异步响应
2. ComfyUI 使用默认部署连接且无 connectionId 时，前端用 SD WebUI 枚举拒绝合法 sampler。本轮按 Provider 与有效连接语义处理动态目录，不改写 ComfyUI sampler 名称，保留服务端最终 fail-closed 预检

## 验收场景

- USER / ADMIN / OWNER 的默认落点、普通个人深链接、管理深链接、退出和会话降权
- 导航、页面挂载、管理操作与真实请求的能力一致性
- 工作台首用空态、首次加载、部分来源失败、重试、重复点击、卸载与账号切换后的过期响应
- 服务能力可用/不可用/未知、错误与空目录；具体执行仍需服务端检查连接、模型和输入
- 默认模型摘要与其他设置弹框使用同一键盘模态契约：打开移入焦点，Tab／Shift+Tab在内部循环，Escape和关闭后恢复打开按钮，背景inert与滚动状态在关闭／卸载后释放。长列表在摘要内部滚动，头尾保留短屏布局约束；DOM与样式契约验证不替代真实浏览器短屏和辅助技术验收
- SettingsMember 标签说明、成员记录失败重试、重复提交互斥、配置草稿与密钥输入在降权时清理
- 平台单项 403 / 503 不掩盖其他成功来源；重试只刷新所选来源
- ComfyUI 默认连接导入 → 保存 → 重新打开 → 运行进入服务端校验；显式连接、空可选值、其他类型错误及非法枚举仍有回归
- 原工作区 37 项改动保持不变；独立增量与 PR #31 兼容
