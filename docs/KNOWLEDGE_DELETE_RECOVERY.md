# 知识库删除与详情切换

知识库及文档删除使用原有确认框和后端接口。确认后发出的删除不会因为返回列表、打开另一库或进入新建向导而取消；成功时仍从共享 store 移除原目标。

删除回执只收尾它拥有的页面意图。甲库操作等待期间打开乙库，甲库成功不把乙库强制切回列表、不清空乙库已完成的检索；甲库失败不覆盖乙库详情，也不留下指向旧操作的重试。若用户重新打开仍待删除的甲库，甲库确认删除后返回列表，不显示共享选择自动回退的另一库详情。每个库独立保留删除等待状态，旧操作结束不解除另一库的等待按钮。

当前详情中的删除失败仍显示可重试错误。显式重试绑定原库或原文档 ID，重新确认后只派发一次原动作，并在新请求开始时移除旧错误；成功后正常显示更新后的文档列表或知识库列表。错误页也可返回知识库列表，或用顶部入口进入新建向导，不会因此再次提交删除。

回归使用真实 Vue 页面和 Pinia store、受控 API 回执与合成标签，不访问实际文件，不执行真实后端删除，也不作为真实检索模型或视觉验收。覆盖文档/库的迟到错误、库迟到成功、同目标重新打开、两个库交错删除、当前错误的显式重试/放弃，以及乙库检索结果的保留。
