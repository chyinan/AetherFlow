# 幂等启动返回既有终态实例

启动回执未收到后，用户明确重试时会继续使用相同幂等键。后端可以返回已成功、失败或取消的原实例，而不是新建运行。编辑器立即应用该回执的真实终态和结束进度，不再写入运行中标记、首节点正在执行或新启动日志，不改写项目摘要，避免把另一条较新运行的运行中标记清除。

启动回执不包含节点详情和归档日志，因此不猜测其执行结果；已有同一实例的已确认终态详情和日志则保留。没有日志缓存时不创建空记录，进入运行详情仍独立读取真实归档和节点状态。读取暂不可用时也不能推翻已确认的运行终态。正常活跃启动保持既有行为。

回归使用真实 Vue、Pinia、Vue Router 和页面启动控制，启动与读取边界由受控 API 替身提供，覆盖超时后相同幂等键返回三个终态。未验证真实后端、外部模型或浏览器视觉。
