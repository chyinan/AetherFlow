# 图像可选枚举与部署默认连接

## 场景

图像节点选择"未指定（服务默认）"后，再改选无 ID 的"使用部署默认连接"，界面保留空字符串并禁用采样器/调度器字段；此前映射层仍发送空串，服务端节点目录把空串当作非法枚举值拒绝保存或运行前保存。

## 契约

- 图像节点的 `sampler`、`scheduler`、`upscaler` 属于可选枚举：空白值统一表示"未指定"，保存与运行前保存不得拒绝
- 非空的非法枚举值仍然拒绝，不放宽白名单
- 配置了连接 ID（含无 ID 的部署默认连接）时，动态可选项仍由 AI Service 按真实服务目录在执行前校验，本契约不变
- 前端映射层不再把空可选枚举序列化进定义；旧数据中的空串在下次保存时被移除
- 运行时收到缺失或空白的可选枚举时沿用部署默认，该行为保持不变

## 验证范围

- 后端校验器：空串/空白可选枚举不产生违规；非空非法枚举仍违规
- 前端映射：空 `sampler`/`scheduler` 不再序列化；非空合法值保留
