# 图像可选枚举与部署默认连接

## 场景

图像节点选择"未指定（服务默认）"后，再改选无 ID 的"使用部署默认连接"，界面按设计保留
空字符串并禁用采样器/调度器字段；但服务端节点目录把空串当作非法枚举值，拒绝保存或运行
前保存，节点无法保存。

## 契约

- 图像节点的 `sampler`、`scheduler`、`upscaler` 属于可选枚举：空白值统一表示"未指定"，
  服务端校验不拒绝，运行载荷也不发送空值，由服务使用自身默认配置
- 非空的非法枚举值仍然拒绝，不放宽白名单
- 配置了连接 ID（含无 ID 的部署默认连接）时，动态可选项仍由 AI Service 按真实服务目录在
  执行前校验，本契约不变
- 定义中的配置值按用户原样保存与回显（空值往返无损），"未指定"的语义在校验层与执行
  载荷层统一，不靠改写用户配置实现
- 已有工作流中的空串配置继续可用，不需要迁移

## 验证范围

- 服务端校验器：空白可选枚举不产生违规；非空非法枚举仍违规
- SD WebUI 载荷：空白采样器/调度器不出现在请求体中；显式取值照常发送
- 前端映射：空可选枚举按原值往返保存，既有保存重开契约不变
