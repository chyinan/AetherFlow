# 工作台打开运行详情：保持当前选择并重试

从个人工作台的“进行中”“失败待查看”或“完成结果”打开一条运行，仍使用原有运行详情地址。同一详情等待时重复点击不再重复导航；用户可以直接改选其他运行。

- 打开期间在原区显示运行名称和 ID。导航被拒或详情页模块加载失败时，如果仍在本页并且没有较新的导航，只在原区显示错误。
- “重试”打开同一运行，不会重新读取区块、重跑工作流。重试时按钮保持在原位置并禁用重复操作，失败后可以再试。
- 另一次导航取代旧目标、主动回到当前地址或离开工作台后，不保留旧失败。链接仍支持原生修饰键和非主键打开。
- 发布后旧页面引用失效资源时，浏览器可能重用失败的模块加载结果；原地重试不保证恢复。仍失败可手动刷新本页，没有自动刷新或自动重试。

验证使用实际 Vue 组件、Pinia、Vue Router 的内存路由与受控 Axios 运行列表，合成运行详情模块的等待、拒绝和恢复。未验证真实浏览器模块缓存、读屏器、布局或后端。
