# 运行日志时区展示

运行日志的 `time` 保留原有兼容显示，新增可选的 `occurredAt` 保存原始时刻。HTTP 历史日志和运行时事件透传来源值；正常本地创建的运行提示、恢复失败和连接提示使用同一个 `Date` 生成原始 ISO 时间及兼容显示。

`LogStream` 在渲染时，使用应用当前语言和已保存的时区格式化有效的原始时刻。因此从设置路由返回、显式刷新或重新挂载时，即使继续复用同一运行的缓存日志，也能显示当前时区。原始时刻、缓存中的 `time`、日志正文及顺序均不因展示而改写，刷新期间的实时日志合并优先级保持不变。

没有原始时刻的旧日志、静态演示日志和无效日期沿用原有 `time`，不能从时分秒字符串推断原始时间。本次不增加其他标签页 `storage` 事件的即时响应，也不改变运行控制或实时连接行为。

回归覆盖三种语言下的 UTC、东京、上海及设备时区展示，原始来源不变，旧值回退，本地日志创建，以及同 ID 的实时日志在 HTTP 刷新期间继续优先。组件和通道接线测试使用 jsdom 与受控接口，不代表真实浏览器、原生历史导航、实际实时连接、后端或 Provider 验证。
